# Лабораторная работа №4 — Unit-тесты

Учебный геометрический калькулятор на Python. Вычисляет площадь и периметр
прямоугольника, квадрата, круга и треугольника.

## Запуск программы

Требуется Python 3.10 или новее. Внешние пакеты не нужны.
Команды выполняются из папки проекта.

```bash
python3 main.py rectangle 3 4
python3 main.py square 5
python3 main.py circle 2
python3 main.py triangle 3 4 5
```

В Windows вместо `python3` можно использовать `py`.

## Требования к данным

Функции принимают `int` и `float` от 0 до 1 000 000 000 включительно.
Строки, `None`, логические значения и контейнеры приводят к `TypeError`.
Отрицательные числа, слишком большие размеры, `NaN` и бесконечность приводят
к `ValueError`. Верхняя граница является требованием этого учебного продукта.

У прямоугольника, квадрата и круга нулевые размеры разрешены для проверки
граничных случаев. Например, `area(10, 0) == 0` у прямоугольника.
Для треугольника требуются три положительные стороны и строгое неравенство
треугольника. Его площадь вычисляется по формуле Герона.

## Запуск unit-тестов

```bash
python3 -m unittest discover -s tests -v
```

Отдельный файл и отдельный тест:

```bash
python3 -m unittest tests.test_rectangle -v
python3 -m unittest tests.test_rectangle.RectangleTestCase.test_zero_second_side -v
```

`unittest` входит в стандартную библиотеку Python: устанавливать его через pip не нужно.
Успешный запуск заканчивается сообщением `Ran 51 tests` и `OK`.
`subTest` перебирает несколько наборов данных внутри одного тестового метода;
они не увеличивают число в строке `Ran ... tests`.

## Скачать и запустить

```bash
git clone https://github.com/areym812/LAB4ISRPO.git
cd LAB4ISRPO
python3 -m unittest discover -s tests -v
```

На странице GitHub можно выбрать **Code → Download ZIP**, распаковать архив,
открыть его папку в VS Code и выполнить команду тестирования в терминале.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `geometry/` | Формулы и проверка входных данных |
| `main.py` | Консольный интерфейс для проверки программы |
| `tests/` | 5 классов и 51 unit-тест |
| `docs/` | Отчёт, протоколы и материалы для защиты |

Тесты работают без сети и внешних библиотек. Консольные проверки описаны
отдельно: они не входят в количество unit-тестов. Покрытие строк и ветвей не
измерялось; 51 успешный тест не означает проверку всех возможных входов.

Документация unittest: https://docs.python.org/3/library/unittest.html
