# Лабораторная работа №4 — Unit-тесты

Учебный геометрический калькулятор на Python. Вычисляет площадь и периметр
прямоугольника, квадрата, круга и треугольника.

## Запуск программы

Требуется Python 3.10 или новее. Внешние пакеты не нужны.
Команды выполняются из папки проекта.

```bash
python3 main.py rectangle 3 4
python3 main.py square 5
python3 main.py circle 2
python3 main.py triangle 3 4 5
```

В Windows вместо `python3` можно использовать `py`.

## Требования к данным

Функции принимают `int` и `float` от 0 до 1 000 000 000 включительно.
Строки, `None`, логические значения и контейнеры приводят к `TypeError`.
Отрицательные числа, слишком большие размеры, `NaN` и бесконечность приводят
к `ValueError`. Верхняя граница является требованием этого учебного продукта.

У прямоугольника, квадрата и круга нулевые размеры разрешены для проверки
граничных случаев. Например, `area(10, 0) == 0` у прямоугольника.
Для треугольника требуются три положительные стороны и строгое неравенство
треугольника. Его площадь вычисляется по формуле Герона.
